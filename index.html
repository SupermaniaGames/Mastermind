How to play

  • One player hides a secret code: a row of 4 coloured pegs (or 5 in the longer game). The other player, the codebreaker, has to crack it.
  • Tap a colour at the bottom to fill the next hole in the highlighted row, then tap Submit. Tap a peg in the row to take it out again.
  • After each guess, small feedback pegs appear beside the row. A black peg means one peg is the right colour in the right place. A white peg means one peg is the right colour in the wrong place.
  • The feedback pegs do not tell you which of your pegs they are about, and their order means nothing. Use them to work out the code before your guesses run out.

  • Crack the code before you run out of guesses. If you do not, the codemaker wins and the code is revealed.
  • Each peg in the code can only be matched once. If the code has two reds and you guess four reds, you get at most two pegs for red.
  • Black pegs are counted first. White pegs are then given for the colours that are left over, so a colour is never counted twice.
  • With repeats off, the code never uses a colour twice. Your guesses can still repeat a colour if you want to test one.
  • Fewer guesses is better. In a series with friends, the player who cracks the code in fewer guesses wins the round.

  • Computer: you try to crack a code the computer made. Easy to Expert change how many guesses you get. You can also let the computer try to crack your code.
  • Pass N Play: one phone, two people. One player sets the code while the other looks away, then you pass the phone and the second player guesses. Press Replay to swap roles.
  • Play with friends: one player creates a room and shares the 4-digit code or the WhatsApp link. You take turns being codemaker and codebreaker in a best of 3 series. You do not have to be online at the same time: leave and come back later to carry on.
  • Setup options: code length 4 or 5, 6 or 8 colours, repeats on or off, and 8, 10 or 12 guesses.
  • Tip: start with a guess that uses several different colours, then use the feedback to rule colours in or out.
